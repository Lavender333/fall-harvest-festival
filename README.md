# Fall Harvest Festival

Public website: https://lavender333.github.io/fall-harvest-festival/

Green Movement Glenville community celebration, October 24, 2026, 11 AM–4 PM Eastern, at 114th & St. Clair in Cleveland.

## Files
Open index.html in a browser. Keep harvest-botanical.png and festival-flyer.jpg in the same folder. No build step is needed. GitHub Pages publishes main from the repository root.

## Features
Flyer-style design, mobile event cards, countdown in America/New_York, downloadable calendar event, original flyer download and sharing, Open Graph tags, sponsor logos displayed from the original flyer, and accessibility improvements.

## Activation needed
Set EVENT_CONFIG.registrationUrl and EVENT_CONFIG.donationUrl in index.html to organizer-verified HTTPS links. Until supplied, the website clearly shows that online registration and direct donation payments are not available. It does not collect submissions or process payments.

Admission price, parking, rain plan, exact street address, and individual activity times need organizer confirmation. No historical photos or personal quotation have been invented.

The botanical harvest illustration is AI-generated. The original flyer was supplied by the organizer/user; logos are displayed from it without redrawing them.
