# Fall Harvest Festival

A responsive community event website for Green Movement Glenville.

## Event
- October 24, 2026, 11 AM–4 PM Eastern
- 114th & St. Clair Avenue, Cleveland, across from Glenville High School

## Website
Open `index.html` in a browser. No build step or dependencies are required. Keep `harvest-botanical.png` alongside it.

Includes event details, activities, directions, calendar download, pre-registration email inquiries, and donation contact information. Registration and donation buttons open email drafts; they do not process payments or store registrations.

The botanical harvest illustration was AI-generated for this website. Other decorative icons are inline SVG.

To host with GitHub Pages, select the `main` branch and root folder in Settings → Pages.
